# Soundtrack of My Heart

Quiz-App: 7 kurze Fragen, daraus 6 Songs (Jugend und heute), eigene Fotos und ein Reel zum Teilen.

- Statische Web-App (PWA), keine Build-Schritte: `index.html`, `manifest.webmanifest`, `sw.js`.
- Lokal testen: `python3 -m http.server 8000` und `http://localhost:8000` öffnen.
- Hör-Vorschau: offizielle 30-Sekunden-Clips der Apple iTunes Search API, nur abspielen.
- Fotos und Antworten bleiben im Browser, es gibt keinen Server.

## Lizenz-Hinweis
Die App mischt keine Original-Songs ins Video. Der Export enthält nur einen selbst erzeugten Platzhalter-Beat. Die Originalmusik legen Nutzer beim Teilen aus der Bibliothek von Instagram oder TikTok darüber. Es gibt keine Sekunden-Freigrenze für Ausschnitte (EuGH, Pelham 2019). Vor dem Start rechtlich prüfen lassen.
